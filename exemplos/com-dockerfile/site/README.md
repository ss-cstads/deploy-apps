# Exemplo: página estática

O exemplo mais simples: um `index.html` e um `Dockerfile` que o serve com nginx (porta 80: `port: 80` no `deploy.yml`). Copie o conteúdo desta
pasta para a raiz do seu repositório, cadastre o `NOMAD_TOKEN`
([passo 2](../../../README.md#2-cadastre-o-seu-token)) e faça push.
